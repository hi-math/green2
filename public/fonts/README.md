# 폰트 파일 안내

## 필요한 폰트 파일

한글 깨짐 방지를 위해 다음 폰트 파일이 필요합니다:

- `JalnanOTF00.woff2` (우선)
- `JalnanOTF00.woff` (폴백)

## 다운로드 방법

1. Jalnan 폰트 다운로드:
   - 원본 CDN: https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_four@1.2/JalnanOTF00.woff
   - 또는 공식 사이트에서 다운로드

2. woff2 변환 (선택사항, 권장):
   - 온라인 변환 도구 사용: https://cloudconvert.com/woff-to-woff2
   - 또는 `woff2` 명령줄 도구 사용

3. 파일 배치:
   - `public/fonts/JalnanOTF00.woff2` (우선)
   - `public/fonts/JalnanOTF00.woff` (폴백)

## 확인

폰트 파일이 올바르게 배치되었는지 확인:
- `public/fonts/JalnanOTF00.woff2` 또는 `public/fonts/JalnanOTF00.woff` 파일 존재 여부
